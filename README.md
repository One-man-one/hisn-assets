# hisn-assets

صور عامة يستخدمها بوت **حصن الزواج**.

`avatar_male.jpg` و`avatar_female.jpg` صورتان تمثيليتان تُنشران مع بطاقات
الملفات على القناة وصفحات التواصل — **لا تُنشر صورة مستخدم حقيقية أبداً**.

المستودع عام لأن إنستجرام لا يقبل رفع بايتات الصورة: يستقبل `image_url`
فقط وسيرفراته هي التي تجلبها، فتلزم روابط مباشرة بلا مصادقة.

- الصيغة: JPEG مربّع 1080×1080 (شروط إنستجرام).
- المصدر: DiceBear بنمط Avataaars — مجاني للاستخدام الشخصي والتجاري.
